# Lawn & Garden Almanac

An interactive, month-by-month plan for your **lawn, flower beds and vegetable garden**, fitted to
your ZIP code anywhere in the United States. It runs entirely in the browser as a static GitHub
Pages site. It has no build step, no accounts and no tracking.

![Lawn & Garden Almanac](assets/og.png)

Type a ZIP code in the bar at the top. The almanac looks up that area's weather history, estimates
its frost dates and hardiness zone, picks the usual lawn grass for the climate, and moves every
task, planting window and weather alert to the local seasons.

- **Lawn plans for six grasses.** Cool-season (tall fescue; bluegrass, ryegrass and fine fescue) and
  warm-season (bermudagrass, zoysiagrass, St. Augustinegrass, centipedegrass), each with its own
  tasks, guide and alerts. Change the grass in Settings.
- **Rain-fed or watered.** Dry climates default to a weekly watering plan; everywhere else the plan
  waters only to keep the lawn alive in a drought.
- **Live weather.** The week planner sets each job on its best day of the forecast.

The plan follows university Extension guidance, backed by recent turf research. Every task links to
its sources and shows how strong the evidence is: Extension, peer-reviewed, product label, vendor
claim or folklore.
